# 第 1 步 / 共 17 步：场景与痛点

> 阶段 1 / 7：**理解任务**

内容理解打标做完 SFT 后，常见的下一步是"上 DPO / RL"。这一课用 7B 在同一个抽取任务上把这件事做一遍，回答四个问题：

1. **偏好数据从哪来**：自己写规则构造坏例子，还是让模型采样、挑它真的会犯的错？
2. **在哪里有信号**：SFT 已经做对的 prompt 上，偏好优化还能学到什么？
3. **会不会跑偏**：参考模型和 β 怎么管住"为了拉开 chosen/rejected 而把别的能力弄坏"？
4. **奖励写成什么样**：可验证奖励只覆盖了部分维度时，没覆盖的维度会怎样？

每个场景都已在 H20 上跑好（3 个种子）。依次点选预测、揭晓、看证据。
