# 第 1 步 / 共 13 步：场景与痛点

> 阶段 1 / 8：**理解任务**

L05 的 7B SFT 基线还有几条错例，最危险的一类是**排除型条件**：原文"满 399 减 40，特价商品除外"，模型输出的优惠条件里把"特价商品除外"丢了，等于告诉下游"全店满减"。

业务上常见的迭代方式是"看到错例 → 补点数据 → 重训 → 指标涨了就上线"。这一课要回答这条路上的三个坑：

1. **噪声**：同一配置换个种子，dev 全对率自己就会抖几个点。涨的那几个点是不是噪声？
2. **归因**：补数据之后整体变好，是目标错误被修好了，还是别处随机变好了？有没有弄坏别的？
3. **上线**：离线 dev 上的提升，换一份没见过的 test 还在吗？推理链路和训练链路一致吗？

每个场景都已在 H20 上跑好（基线和主改动 5 个种子）。依次点选预测、揭晓、看证据。
