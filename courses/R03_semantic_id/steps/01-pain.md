# 第 1 步 / 共 15 步：场景与痛点

> 阶段 1 / 7：**理解任务**

生成式召回（TIGER、OneRec）让模型逐个 token 生成物品 ID。直接用原始 ID 的问题：

- **输出层太大**：1000 万个物品 × d = 128 就是 12.8 亿参数，softmax 每步都要算全部；
- **没有泛化**：冷启动物品的 ID 向量没训练过，相似物品之间也不共享任何东西。

语义 ID 用几层离散码表示一个物品：相似物品共享前缀，词表只有几百个 token。但码的质量决定了召回的上限：撞码的物品分不开、前缀没语义就学不到泛化。这一课把这些量化出来。每个场景都已在 H20 上跑好。
