# 第 1 步 / 共 19 步：场景与痛点

> 阶段 1 / 7：**理解任务**

特征迭代是精排日常工作的大头。两类误判最常见：

- **把噪声当收益**：单种子 +0.2 个点就写进周报；
- **把穿越当收益**：统计特征离线一次性算好再拼回样本，样本看到了自己的标签和未来，离线涨 2-3 个点，上线持平甚至下跌。

内容理解 LLM 产出的标签、embedding 进推荐模型时，也是一组"新特征"：它的收益落在哪类用户 / 物品、和 ID 特征是不是重复、产出口径和线上是否一致，都要按这一课的方法验证。每个场景都已在 H20 上跑好。
